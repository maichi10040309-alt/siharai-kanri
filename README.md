# 仕入・支払管理

各部門の請求入力、経費集計、紀陽銀行のネットバンキングへ取り込む総合振込データの作成を行うブラウザアプリです。

## 主な機能

- 販売・レンタル、給食、治療院など部門別の請求管理
- 請求月と部門を選び、登録取引先へ表形式で連続入力
- 取引先ごとに複数の対象部門を設定
- 1件の請求を複数の経費科目へ分割
- 月別・部門別・科目別の経費集計
- 取引先と振込口座のマスタ管理
- 紀陽銀行の全銀協120バイト形式（総合振込）の出力
- JSONバックアップの書き出し・復元

## 利用方法

静的ファイルのみで動作します。`index.html` をWebサーバーで配信してください。

```bash
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開きます。最初に「設定・バックアップ」で振込依頼人情報を、「取引先マスタ」で振込先を登録してください。

## データ保存と注意事項

入力データはブラウザの `localStorage` にのみ保存され、GitHubには送信されません。別端末との自動同期はありません。定期的に設定画面からバックアップを保存してください。ブラウザデータを削除すると、バックアップしていない内容は復元できません。

全銀ファイルは紀陽銀行公開の「総合振込全銀フォーマット」に従い、ヘッダー・データ・トレーラ・エンドを各120バイト、改行CRLFで作成します。初回利用時は銀行側のテストまたは少額データで取込結果を確認してください。
